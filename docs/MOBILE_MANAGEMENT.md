# 手机查询与管理（1.1.0）

手机端提供四个入口：概览、用户、账号、服务器。保留连接后台所需的服务器设置，隐藏新增账号、分组配置等日常查询不需要的导航入口。

## 日常操作

- **概览**：查看请求、消费、用户与账号统计，按今日、7天、30天查看趋势。可选统计接口失败时仍显示可用数据。
- **用户**：搜索及分页查询、余额调整、启用/停用；API Key 默认隐藏，可查看限额、已用额度、有效期。
- **用户订阅**：查询日/周/月限额、已用与剩余、重置时间；选择周期重置额度，或按天延长有效期。
- **账号**：搜索及分页查询，识别限流、临时暂停、过载冷却、过期与错误；查看上游窗口额度、今日消费、重置卡余额；测试、暂停/恢复调度、清除错误、本地额度重置。
- **重置卡**：支持后台提供的 Claude 与 OpenAI/Codex 查询和使用接口。只有返回符合资格、可用卡且支持操作的账号显示使用入口；影子账号可跳转主账号。
- **服务器**：添加、验证、切换及移除手机保存的连接。切换时清理旧缓存，并拒绝旧会话的请求结果和确认操作。

本地 API Key 额度、用户订阅额度、上游服务商额度是三个不同对象，页面分别说明操作影响。上游重置卡消耗不可撤回，执行前显示确认；写入无自动重试。结果不确定时要求重新查询。支持幂等键的充值、延期和 Claude 操作沿用原编号，未决状态在本次应用运行期间跨页面保留；重启应用后应先核对后台结果。

## 后台要求

连接你的 Sub2API 服务器地址及 Admin Key；Android 使用系统安全存储保存连接，Web 不持久化 Admin Key。

接口根据 `Wei-Shaw/sub2api` 0.2.13 源码核对（提交 `b8dece9000c68815a5b867ca5a1e6f236e173905`）。Claude 重置卡使用需要支持相应兑换接口的后台（0.2.12 或更新）；OpenAI 重置、用户订阅管理同样取决于部署版本与账号类型。接口不存在时显示版本不支持，权限错误、网络失败或未知额度不会显示为操作成功或零用量。

## 验证与打包

```bash
npm ci
npm run typecheck
npm test
```

浏览器手机布局检查使用模拟接口，不连接真实后台；需要 Playwright 与 Chromium，并提前启动 Web 服务：

```bash
npm run web -- --host localhost --port 8082
# 在另一个终端；系统提供 Playwright 时可通过 NODE_PATH 指定其目录
MOBILE_TEST_URL=http://localhost:8082 npm run test:browser
```

APK 为独立 Release 包，包含 JavaScript，无需 Metro。当前云环境使用 Android SDK 36、NDK 27.1、JDK 17 与 Gradle，针对 ARM64/ARMv7 构建。此 APK 采用与之前 1.0.0 相同的测试签名，用于直接安装；正式商店发布应使用自己的发行签名。

未提供真实后台凭据，本次验证包含类型检查、接口契约、模拟手机操作与 APK 签名/结构检查；不包含真实重置卡消费、真实订阅写入或手机实机验证。
